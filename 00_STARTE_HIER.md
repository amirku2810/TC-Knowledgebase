# TradeControl Knowledge Base

Starte immer mit diesem Dokument, bevor du mir die passende Antwort heraussuchst.

## Zweck

Diese Knowledge Base beschreibt das ERP-System TradeControl,
dessen internes PowerBuilder Framework PfuFun, die zugehörigen
Libraries, Programme, Datenbankstrukturen und projektspezifischen
Anpassungen.

## Technologie

- PowerBuilder 12.6
- Microsoft SQL Server
- PowerBuilder Libraries (.pbl)
- DataWindows
- Windows / NonVisualObjects
- Global Functions
- PfuFun Framework

## Wichtige Begriffe

### PfuFun

PfuFun bezeichnet das intern entwickelte Framework,
auf dem TradeControl basiert.

Es erweitert bzw. standardisiert die nativen PowerBuilder-
Funktionen und Events.

### Library

Eine PowerBuilder Library (.pbl), welche unter anderem
Windows, DataWindows, NonVisualObjects und Functions enthält.

### Projekt

Ein Projekt entspricht grundsätzlich einer TradeControl-
Installation bzw. einem Kunden.

Projekte können vom Standard abweichende Implementierungen
oder Erweiterungen enthalten.
